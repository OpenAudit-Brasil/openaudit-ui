# Code of Conduct — OpenAudit Brasil

## 1) Objetivo
Este projeto existe para construir uma infraestrutura open source, auditável e responsável para análise de dados públicos. Para isso, a comunidade precisa operar com respeito, neutralidade e rigor técnico.

## 2) Escopo
Este Código de Conduta se aplica a todas as interações do projeto, incluindo (mas não limitado a):
- Issues, Pull Requests e Discussions no GitHub
- Comentários em commits e revisões de código
- Canais oficiais de chat/comunidade vinculados ao projeto
- Eventos e encontros relacionados ao projeto

## 3) Valores fundamentais
- **Respeito**: critique ideias, não pessoas.
- **Rigor**: prefira evidência, método e rastreabilidade.
- **Neutralidade**: o projeto não é palco para propaganda político-partidária.
- **Responsabilidade**: nenhuma inferência deve ser apresentada como acusação.
- **Segurança**: evitar ações que exponham dados pessoais, risco jurídico ou reputacional.

## 4) Comportamentos esperados
- Ser educado, direto e objetivo.
- Discordar com argumentos técnicos e verificáveis.
- Ajudar iniciantes e revisar com clareza.
- Apontar riscos (técnicos/jurídicos/reputacionais) de forma construtiva.
- Respeitar escopo e prioridades do projeto.
- Reportar problemas de segurança de modo responsável (ver seção 9).

## 5) Comportamentos inaceitáveis
- Ataques pessoais, humilhação, intimidação ou assédio.
- Discurso de ódio, discriminação ou incentivo à violência.
- Conteúdo político-partidário, propaganda, campanhas ou “calls to action” eleitorais.
- Difamação: acusações, insinuações de crime/corrupção, ou “exposição” de indivíduos.
- Publicar ou solicitar **dados pessoais** (PII) sem base legal e sem necessidade técnica.
- “Doxxing” (endereços, telefones, documentos, informações privadas).
- Spam, flood, trolling, flame wars.
- Incentivar violação de termos de uso, scraping agressivo, bypass de bloqueios ou qualquer prática ilegal.

## 6) Regras específicas para um projeto de transparência/OSINT
Este projeto prioriza linguagem e processos defensáveis:

**Sempre use termos como:**
- anomalia estatística
- padrão atípico
- inconsistência estrutural
- divergência documental

**Evite:**
- “culpado”, “corrupto”, “criminoso”, “fraude confirmada”, “prova”, etc.

**Separação obrigatória:**
- análise automatizada ≠ conclusão
- sinal ≠ acusação

Quando houver integração com dados, exigimos:
- origem da fonte
- data de coleta
- versão do dado
- transformações aplicadas
- limitações/viés do método

## 7) Moderação e aplicação
Os mantenedores do projeto podem tomar medidas para proteger a comunidade, incluindo:
- Solicitar alterações no tom ou conteúdo
- Remover conteúdo inadequado (comentários, issues, PRs)
- Bloquear ou banir temporária/permanentemente contas que violem as regras
- Encerrar discussões que degenerem em conflito improdutivo

A severidade da ação depende do impacto e recorrência:
- aviso → remoção de conteúdo → restrição temporária → banimento

## 8) Como pedir ajuda / resolver conflitos
- Se um conflito surgir, mantenha a discussão no mérito técnico.
- Se a conversa escalou, peça intervenção de um mantenedor.
- Se necessário, leve o tema para uma Issue separada com escopo bem definido.

## 9) Segurança e reporte responsável
Se você identificar vulnerabilidades, vazamento de dados, credenciais ou qualquer risco de segurança:
- **Não publique em issue pública.**
- Reporte para: **comunidade@openauditbrasil.com**

Inclua, quando possível:
- passos para reproduzir
- impacto estimado
- evidências mínimas (sem expor PII)

## 10) Atribuição
Este Código de Conduta é inspirado em práticas amplamente adotadas por comunidades open source (incluindo o Contributor Covenant), adaptado ao contexto específico de um projeto de transparência pública e análise responsável.

---
Ao participar do projeto, você concorda em seguir este Código de Conduta.
